# 🛒 Thakran Electronics

Thakran Electronics is a full-stack e-commerce web app for buying computer products. It includes user and admin modules for shopping, product management, and order handling, built according to the Web Term Project guidelines.

## 📜 Project Description

Thakran Electronics is an **Online Computer Store** where users can:

- Browse products by category
- View product details
- Add products to cart
- Checkout and place orders
- Register / Login / Logout
- View their order history

Admin users can:

- Add, edit, delete products
- View all orders placed by customers
- Manage user orders

## 🚀 Features

### User Features

- User Registration & Login
- Secure password hashing
- View product listings & details
- Add / remove items in cart
- Checkout system
- Order history tracking

### Admin Features

- Admin login panel
- Add / Edit / Delete products
- Manage stock & categories
- View all customer orders

## 📦 Installation & How to Run the Project

### 1️⃣ **Install XAMPP**

Download and install XAMPP (Apache + PHP + MySQL).

### 2️⃣ **Move Project Folder**

Copy the whole folder **thakran-electronics** into:

```
C:\xampp\htdocs\
```

---

### 3️⃣ **Create Database**

1. Open phpMyAdmin:
   👉 [http://localhost/phpmyadmin](http://localhost/phpmyadmin)
2. Create a database named: **thakran_electronics_db**
3. Import the SQL file:`thakran_electronics_db`
